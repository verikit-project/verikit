# Waitlist example

A waitlist anyone can join through the API, and an admin manages in an admin
panel. It shows the parts of Verikit a real app needs beyond the starter:

| Where                       | What it shows                                                      |
| --------------------------- | ------------------------------------------------------------------ |
| `resources/signup.ts`       | A resource generated by `verikit make:resource`, then customized   |
| `server/permissions.ts`     | Public create, admin-only everything else, down to field level     |
| `server/actor.ts`           | Turning a request into the `actor` that permission rules receive   |
| `resources/signup.actions.ts` | The `invite` action's declaration: label and confirmation, shown in the panel |
| `actions/signup/invite.ts`  | Its server-side handler: an availability rule, and a database write |
| `src/App.tsx`, `src/admin-token.ts` | The panel's `auth` hook, and a new client per sign-in      |
| `test/api.test.ts`          | API tests against the real server and an in-memory database        |

## Run it

From the repository root:

```sh
pnpm install
pnpm build
cd examples/waitlist-sqlite
cp .env.example .env   # sets ADMIN_TOKEN=change-me
pnpm dev               # http://localhost:3000, sign in with the token
```

Join the waitlist as a member of the public:

```sh
curl -X POST localhost:3000/api/signup \
  -H 'content-type: application/json' \
  -d '{"email":"you@example.com","source":"friend"}'
```

Invite someone as the admin, or use the Invite button on each row in the panel:

```sh
curl -X POST localhost:3000/api/signup/actions/invite \
  -H 'authorization: Bearer change-me' -H 'content-type: application/json' \
  -d '{"recordId":"<id from the panel>","confirmed":true}'
```

## Checks

`pnpm smoke` confirms the generated files are current, type-checks, and runs
the API tests. The repository's smoke test runs it for every example, so this
app keeps working as Verikit changes.

## How it was made

```sh
npm create verikit@latest waitlist-sqlite
npx verikit make:resource Signup email:email name:text? \
  source:select:friend,search,social,other? status:select:waiting,invited
npx verikit make:action signup invite
npm run db:generate
```

Then the edits described in each file's comments: a unique email, a status
that defaults to `waiting`, the permissions, the actor, the invite action, and
the admin sign-in.

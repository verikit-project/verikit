# Docusaurus Setup

This `docs/` directory is ready to copy into a Docusaurus project.

## Option 1: Create a docs app

From the repository root:

```sh
pnpm create docusaurus apps/docs classic --typescript
```

Then copy or move this directory into `apps/docs/docs`.

## Option 2: Use this directory as the Docusaurus docs path

If your Docusaurus app lives inside the repo, point `docusaurus.config.ts` at this docs folder:

```ts
import type { Config } from "@docusaurus/types";

const config: Config = {
  title: "Verikit",
  url: "https://verikit.dev",
  baseUrl: "/",
  presets: [
    [
      "classic",
      {
        docs: {
          path: "../../docs",
          routeBasePath: "/",
          sidebarPath: "./sidebars.ts",
        },
        blog: false,
      },
    ],
  ],
};

export default config;
```

Adjust `path` based on where the Docusaurus app lives.

## Suggested sidebar

Docusaurus can infer sidebars from the folder structure and `_category_.json` files.

```ts
import type { SidebarsConfig } from "@docusaurus/plugin-content-docs";

const sidebars: SidebarsConfig = {
  docs: [{ type: "autogenerated", dirName: "." }],
};

export default sidebars;
```

## TypeDoc integration

For generated API docs, install TypeDoc and the Markdown plugin:

```sh
pnpm add -D typedoc typedoc-plugin-markdown
```

Then generate Markdown into `docs/api/generated`.

```json
{
  "entryPoints": [
    "packages/core/src/index.ts",
    "packages/runtime/src/index.ts"
  ],
  "out": "docs/api/generated",
  "plugin": ["typedoc-plugin-markdown"],
  "readme": "none"
}
```

Generated API pages are best treated as reference material. Keep the hand-written guides as the main learning path.
